Shortcut Setup Guide

Apple blocks downloading Shortcut files from the web. But don't worry! Enter your API key below and we'll generate the exact values you need to copy/paste into your Shortcut app.

How to configure it

1 Open the Shortcuts app

Create a new Shortcut and add the Get Clipboard action.

2 Add "Get Contents of URL"

Add the Get Contents of URL action and paste this exact link:

https://...

3 Configure the URL Request

Tap the blue arrow `>` to expand the URL action options.

  • Change Method to POST
  • Tap "Add new header"
  • Key: Authorization
  • Text: Paste the exact string below (it includes the word Bearer and a space):
Bearer ...
Crucial: Do not forget the word "Bearer " before your key, otherwise it will fail!

4 Add Request Body

  • Change Request Body to JSON
  • Tap "Add new field" → Text
  • Key: url
  • Text: Tap the field, tap the `{x}` variable icon above the keyboard, and select Clipboard.

5 Finish up!

Add the Save to Photo Album action at the very bottom. You're done!
